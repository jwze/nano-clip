## 1. 安装

### 1.1 从源码构建

需要 Xcode 命令行工具（`xcode-select --install`）和 Swift 6 工具链。

```bash
git clone <仓库地址> NanoClip
cd NanoClip

./Scripts/build-app.sh     # release 构建 → 生成图标 → 打包 build/NanoClip.app → 签名
./Scripts/install.sh       # 复制到 /Applications 并启动
```

`build-app.sh` 做了什么：

| 步骤 | 说明 |
| --- | --- |
| `swift build -c release` | 加 `-Xlinker -dead_strip` 裁剪死代码，减小体积 |
| 组装 `.app` | `Contents/MacOS/NanoClip` + `Info.plist` + `PkgInfo` |
| 生成图标 | `Resources/AppIcon.icns` 不存在时运行 `Scripts/GenerateAppIcon.swift` 现场生成 |
| `strip -x` | 去掉本地符号（运行期用不到） |
| `codesign` | 默认 ad-hoc（`--force --sign -`）；`SIGN_IDENTITY` 可换成自签名证书 |

可选参数：

```bash
CONFIG=debug ./Scripts/build-app.sh        # 用 debug 配置打包
SIGN_IDENTITY="NanoClip Local" ./Scripts/build-app.sh   # 用自签名证书（签名稳定）
```

### 1.2 只跑不打包

```bash
swift run NanoClip --show-history      # 直接跑可执行文件，启动即开面板
```

> 注意：`swift run` 启动的是裸二进制，不是 `.app`，此时「登录时自动启动」会提示无法定位应用。

## 2. 首次配置

### 2.1 确认已启动

启动后**没有 Dock 图标**（`LSUIElement = true`），只在菜单栏出现一个剪贴板图标。代表它在跑：

```bash
pgrep -x NanoClip
```

### 2.2 不需要任何系统权限

NanoClip 只把内容写回剪贴板，**不注入 ⌘V**，也不需要「辅助功能」「输入监控」等授权。

双击 ⌥（默认呼出方式）同样不需要授权：它没有监听键盘事件，只是每 25ms 查询一次系统当前的修饰键状态（`CGEventSource.flagsState`），这个查询对任何进程都开放。

验证当前状态：

```bash
/Applications/NanoClip.app/Contents/MacOS/NanoClip --diagnostics
```

输出里的 `hotkey:`、`launchAtLogin(system):`、`items:`、`imageBytes:`、`rss:` 就是全部运行时状态。

### 2.3 开机自启

首次启动会自动通过 `SMAppService` 注册登录项（无需 LaunchAgent 辅助文件）。
想关闭：偏好设置 → 通用 → **登录时自动启动**（开关）。

> `SMAppService` 要求 App 位于 `/Applications`，从 `build/NanoClip.app` 直接运行会显示「无法定位应用」。

### 2.4 确认快捷键

默认**双击 ⌥（Option）**呼出面板，再双击一次或按 `esc` 收起。

想换成组合键：偏好设置 → 呼出快捷键 → 点按钮，然后直接按组合键（如 ⌘⇧V），
也可以双击 ⌘ / ⌃ / ⇧ 把呼出方式改成双击那个修饰键（见 [4.1](#41-快捷键)）。

## 3. 日常使用

### 3.1 基本流程

```
复制任意文本/图片  →  双击 ⌥ 呼出面板  →  单击或 ↑↓+↩ 复制  →  ⌘V 粘贴
```

- 面板会在你**当前所在的 App** 上弹出，关闭后焦点自动回到该 App。
- 面板列出的每一项显示：缩略图/文本预览、来源 App、时间。
- **单击任意一行即复制**并收起面板，随后按 `⌘V` 即可粘贴到刚才的位置。
- 点击一条旧记录**不会新增一行**：原记录的时间戳刷新后排到列表最前（内容不变、不重复）。

### 3.2 面板长什么样

面板是白色 HUD 风格，左侧竖排导航栏 + 右侧内容区：

```
┌────┬──────────────────────────────┐
│ N  │ ⌕ 搜索剪贴板…          ESC   │
│ ▦  ├──────────────────────────────┤
│ ≡  │ 19 ITEMS              全部时间 ⌄│
│ ⇢  ├──────────────────────────────┤
│ ▣  │ ▍标题                       │
│    │  来源 · 时间                 │
│ ⚙  │ …                            │
└────┴──────────────────────────────┘
```

- **左栏**：顶部是品牌标；中间四个图标依次是 全部 / 文本 / 链接 / 图片 分类过滤；底部齿轮直接打开设置。
- **右栏**：搜索框 → 条目数与时间筛选 → 列表 → 底部按键提示。
- 选中行是青色玻璃药丸 + 左侧青色竖条；鼠标悬停是更淡的一层。

### 3.3 快捷键总表

| 操作 | 按键 |
| --- | --- |
| 呼出 / 关闭面板 | 双击 `⌥`（可改成任意组合键） |
| 上下选择 | `↑` `↓` |
| 复制选中项 | `↩`（鼠标单击行等效） |
| 关闭面板 | `esc` |
| 删除当前项 | `⌘⌫` |
| 打开偏好设置 | `⌘,` |
| 搜索 | 直接打字（无需点搜索框，呼出即已聚焦） |
| 按分类筛选 | 点左侧竖排图标：全部 / 文本 / 链接 / 图片 |
| 按时间筛选 | 列表上方的「全部时间 ⌄」 |
| 打开设置 | 面板左下角齿轮（或 `⌘,`） |

### 3.4 搜索

- 呼出面板后直接输入即可实时过滤（中文输入法打字过程中也会即时筛选），点输入框右侧 `×` 或按 `⌘⌫` 清空。
- 匹配的是文本内容；模糊大小写不敏感。
- **图片条目只在搜索框为空时出现**（图片没有可搜索的文本）。
- 搜索词含 `%` `_` 等字符时按字面匹配（内部做了 LIKE 转义）。

### 3.5 把旧记录放到最前

单击（或 `↩`）任意旧条目 = 复制它 + 把它移到列表最前：

- 不会产生新条目，也不会改变内容；只是把该行的 `created_at` 更新为当前时间。
- 所以「最近用过的」永远在顶部，重复复制同一内容也只会有一行。

### 3.6 删除

- `⌘⌫` 删除当前选中项；若该项有图片，`images/<sha256>.<原始扩展名>` 同步删除。
- 删除不可撤销（无回收站）。

### 3.7 支持与不支持的内容

| 复制的内容 | 结果 |
| --- | --- |
| 纯文本 | ✅ 记为文本条目（多余空白/换行会被归一化） |
| 富文本（Word、网页、Pages 等） | ✅ **只保留纯文本**，格式全部丢弃 |
| 仅 RTF / HTML（无纯文本类型） | ✅ 从 RTF/HTML 里解出字符串后入库 |
| 图片、截图、复制图片 | ✅ **按原始格式保存**（PNG 还是 PNG，JPEG 还是 JPEG，TIFF 还是 TIFF），不压缩、不转码、不限大小，按内容 SHA-256 去重 |
| Finder 里的文件 / 文件夹 | ❌ 直接跳过：即使粘贴板同时带了文件名文本，也不会把文件名记成一条文本 |
| 密码管理器内容（concealed） | ❌ 默认跳过 |
| 临时 / 自动生成粘贴板内容 | ❌ 跳过（`Transient` / `AutoGenerated`） |
| Universal Clipboard（跨设备粘贴） | ❌ 不记录（`com.apple.is-remote-clipboard`） |
| 超大图片 | ✅ 照常入库（没有大小上限） |

### 3.8 粘贴到哪儿？

- 复制后面板会**激活回**你呼出面板前的前台 App，光标还在原来的输入框里，直接 `⌘V` 就贴到位。
- NanoClip 不会替你按 ⌘V，因此不需要任何系统权限。

## 4. 偏好设置详解

打开方式：点菜单栏图标 → **设置…**（弹窗只有「设置」「退出」两项），或面板左下角齿轮，或 `⌘,`。

### 4.1 快捷键

- 当前呼出方式显示为一个按钮，点击进入录制态（显示「双击 ⌥ 或按下组合键…」）。
- 想用双击修饰键：录制态里**双击同一个修饰键**（⌥ / ⌘ / ⌃ / ⇧）即可，例如双击 ⌥。
- 想用组合键：录制态里直接按，如 ⌘⇧V。必须包含至少一个修饰键，否则提示「需要修饰键，请重按…」。
- 录制中按 `esc` 取消，保持原设置。
- 旁边有「恢复默认」按钮回到默认的双击 ⌥。
- 组合键用 Carbon `RegisterEventHotKey` 注册；双击修饰键靠轮询修饰键状态实现。两者都不需要任何系统权限。
- 已知取舍：轮询只看得见修饰键，不知道两次 ⌥ 之间有没有按别的键，所以「⌥+字母」快速连打有可能被当成双击 ⌥；用不惯就换成组合键。

### 4.2 启动（登录时自动启动）

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 登录时自动启动 NanoClip | 开 | 通过 `SMAppService` 注册；下方会显示系统返回的登录项状态 |

同区域下方会注明：选中或单击条目只复制到剪贴板，不会自动粘贴。

### 4.3 历史与存储

| 选项 | 默认 | 范围 | 说明 |
| --- | --- | --- | --- |
| 不限制保留条数 | 开 | — | 默认无限保留；关掉后按下面的「保留条数」裁剪 |
| 保留条数 | 不限 | ≥ 1 | 关闭「不限制」后生效，超限从最旧的开始删 |
| 记录图片 | 开 | — | 关闭后新复制的图片不再入库（已有图片不受影响）；图片不压缩、不转换、不设上限 |

区域底部显示当前条目数/图片占用等统计。

### 4.4 忽略的 App

- 一张列表，默认已包含：1Password（1Password 7 / AgileBits）、Bitwarden、LastPass、Apple Passwords、钥匙串访问、KeePassXC、Dashlane、Enpass。
- 点 `+` 从「应用程序」里选择 App，加进去后**它复制的内容永远不会入库**。
- 选中一行按 `−`（或删除键）移除。
- 列表下方提示：「这些 App 复制的内容不会被记录。密码类 App 已默认加入。」

### 4.5 清空历史

「清空历史」按钮 = 清空元数据表 + 删除 `images/` 下的所有图片文件，**不可恢复**。

## 5. 隐私行为

- 数据**只在本机**：`~/Library/Application Support/NanoClip/`，不加密落盘、无云同步、无网络请求。
- 日志只记录条目数量/类型/耗时，**不记录剪贴板内容**（`NanoClip.log` 超过 512KB 自动截断）。
- 采集前过滤三类内容：忽略 App 名单、concealed/transient 类粘贴板类型、远端剪贴板类型。
- 程序不做任何联网行为，零第三方依赖。

## 6. 数据与清理

### 6.1 目录结构

```
~/Library/Application Support/NanoClip/
├─ history.sqlite3 (+ -wal / -shm)   # 元数据（WAL 模式）
├─ images/<sha256>.<ext>             # 图片实体，原格式保存，内容寻址，天然去重
└─ NanoClip.log                      # 运行日志
```

偏好设置（快捷键、条数、忽略名单等）存在 `UserDefaults`：

```bash
defaults read com.jvz.nanoclip
```

### 6.2 查看数据库

```bash
sqlite3 ~/Library/Application\ Support/NanoClip/history.sqlite3 \
  "select id, kind, substr(content,1,40), image_bytes, source_app, pinned
   from items order by created_at desc limit 10;"
```

### 6.3 手工清理

```bash
# 只清图片（元数据仍保留，预览会缺失——不建议）
du -sh ~/Library/Application\ Support/NanoClip/images

# 彻底重置：先退出 App
pkill -x NanoClip
rm -rf ~/Library/Application\ Support/NanoClip
defaults delete com.jvz.nanoclip       # 连偏好设置一起重置
```

### 6.4 命令行启动参数

| 参数 | 作用 |
| --- | --- |
| `--show-history` | 启动即展开历史面板 |
| `--show-preferences` | 启动即打开偏好设置 |
| `--diagnostics` | 打印诊断信息（内存、条目数、登录项）后退出 |

```bash
open -a NanoClip --args --show-history
/Applications/NanoClip.app/Contents/MacOS/NanoClip --diagnostics
```

调试界面时可用环境变量 `NANOCLIP_DARK=1` 强制深色外观，不必切换系统设置：

```bash
NANOCLIP_DARK=1 /Applications/NanoClip.app/Contents/MacOS/NanoClip --show-history
```

## 7. 卸载

```bash
# 1. 退出并关闭登录项
osascript -e 'quit app "NanoClip"'
#    或在偏好设置里先取消「登录时自动启动」，否则系统可能留下登录项记录

# 2. 删除 App 和用户数据
rm -rf /Applications/NanoClip.app
rm -rf ~/Library/Application\ Support/NanoClip
defaults delete com.jvz.nanoclip

```

## 8. 故障排查

### 双击 ⌥ 没反应

1. 确认在跑：`pgrep -x NanoClip`。
2. 双击要**快**：间隔约 0.45 秒以内、每次按住不超过 0.45 秒才算一次双击。
3. 双击过程中不要同时按其他修饰键（⌘/⌃/⇧），那样会被当成组合键而放弃。
4. 换成组合键试试：偏好设置 → 呼出快捷键 → 录制一个组合键。组合键注册失败会弹窗提示。
5. 看日志：`tail -f ~/Library/Application\ Support/NanoClip/NanoClip.log`。

### 复制后没有自动粘贴

- 这是设计如此：NanoClip 只做复制，不注入 ⌘V。选中条目后自己按 `⌘V` 即可。
- 若 ⌘V 没反应，先确认剪贴板内容已更新：`pbpaste | head -1`。

### 「登录时自动启动」提示无法定位应用

`SMAppService` 要求 App 位于 `/Applications`。先用 `Scripts/install.sh` 安装，再在偏好设置里勾选。

### 条目自己消失

- 只有开启了「保留条数」上限才会自动删旧条目；默认不限制，不会自己删。
- 图片不会因为体积被清理，磁盘占用会随历史一起增长，需要时用「清空历史」。

### 图片没被记录

- 检查偏好设置里「记录图片」是否开启。
- 日志里会有 `image rejected` / `skip: imageUnreadable` 之类的记录（示例：粘贴板给的图片数据无法解码）。

### 复制文件后历史里出现了文件名

- 现在不会了：含 `public.file-url`（Finder 复制文件）的粘贴板内容一律跳过，日志里是 `skip: filesOnly`。
- 如果还看到历史里只有文件名的旧条目，那是升级前采集的，删掉即可。

### 内存看起来偏高

`ps -o rss` 会把 AppKit/Foundation 等共享框架页也算进去（空 AppKit agent 也有 ~68MB）。
用活动监视器的「内存」口径（phys_footprint）才准确：

```bash
footprint -p "$(pgrep -x NanoClip)"    # 空闲约 16MB，反复开合面板后约 26MB 并稳定
```

### 数据库损坏

```bash
pkill -x NanoClip
sqlite3 ~/Library/Application\ Support/NanoClip/history.sqlite3 "pragma integrity_check;"
# 修不好就删库重来（历史会丢）：
rm -f ~/Library/Application\ Support/NanoClip/history.sqlite3*
```

### 面板弹出但空白

- 刚启动时数据库为空属正常，先复制点东西。
- 搜索框可能残留上次的搜索词，`⌘⌫` 清空。
- 历史被清空过 → `images` 与元数据都不存在了。

### 查看运行期诊断

```bash
/Applications/NanoClip.app/Contents/MacOS/NanoClip --diagnostics
```

会输出：bundle / version / hotkey / launchAtLogin(pref+system) / maxItems / recordImages / ignoredApps / store 路径 / items / imageItems / imageBytes / orphanImagesRemoved / rss。
注意它只报 RSS，phys_footprint 用上面的 `footprint` 命令看。

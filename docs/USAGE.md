## 1. 安装

### 1.1 从源码构建

需要 Xcode 命令行工具（`xcode-select --install`）和 Swift 6 工具链。

```bash
git clone <仓库地址> NanoClip
cd NanoClip

./Scripts/build-app.sh     # release 构建 → 生成图标 → 打包 build/NanoClip.app → 签名
./Scripts/install.sh       # 复制到 /Applications 并启动
```

`build-app.sh` 做了什么：

| 步骤 | 说明 |
| --- | --- |
| `swift build -c release` | 加 `-Xlinker -dead_strip` 裁剪死代码，减小体积 |
| 组装 `.app` | `Contents/MacOS/NanoClip` + `Info.plist` + `PkgInfo` |
| 生成图标 | `Resources/AppIcon.icns` 不存在时运行 `Scripts/GenerateAppIcon.swift` 现场生成 |
| `strip -x` | 去掉本地符号（运行期用不到） |
| `codesign` | 默认 ad-hoc（`--force --sign -`）；`SIGN_IDENTITY` 可换成自签名证书 |

可选参数：

```bash
CONFIG=debug ./Scripts/build-app.sh        # 用 debug 配置打包
SIGN_IDENTITY="NanoClip Local" ./Scripts/build-app.sh   # 用自签名证书（保留辅助功能授权）
```

### 1.2 只跑不打包

```bash
swift run NanoClip --show-history      # 直接跑可执行文件，启动即开面板
```

> 注意：`swift run` 启动的是裸二进制，不是 `.app`，此时「登录时自动启动」会提示无法定位应用。

## 2. 首次配置

### 2.1 确认已启动

启动后**没有 Dock 图标**（`LSUIElement = true`），只在菜单栏出现一个剪刀板图标。代表它在跑：

```bash
pgrep -x NanoClip
```

### 2.2 授予辅助功能权限（重要）

自动粘贴需要向当前应用注入 ⌘V，这属于「控制其他 App」，必须授权：

1. 桌面左上角  → **系统设置** → **隐私与安全性** → **辅助功能**
2. 点 `+`，选择 `/Applications/NanoClip.app`（或从列表里打开开关）
3. 若已经勾选但仍不生效，**先移除再加回**（ad-hoc 签名重建后 cdhash 变化，旧授权会失效）

未授权时程序不会报错，而是**降级为仅复制**：回车把内容放进剪贴板，面板底部显示
「未授予辅助功能权限：回车仅复制到剪贴板」，右侧有「去授权」按钮可直接跳转设置页。

验证当前状态：

```bash
/Applications/NanoClip.app/Contents/MacOS/NanoClip --diagnostics
```

输出中 `accessibilityTrusted: true` / `false` 即为当前状态（其他行：`hotkey:`、`launchAtLogin(system):`、`items:`、`imageBytes:`、`rss:`）。

### 2.3 开机自启

首次启动会自动通过 `SMAppService` 注册登录项（无需 LaunchAgent 辅助文件）。
想关闭：菜单栏菜单 → **登录时自动启动**，或偏好设置里取消勾选。

> `SMAppService` 要求 App 位于 `/Applications`，从 `build/NanoClip.app` 直接运行会显示「无法定位应用」。

### 2.4 确认快捷键

默认 **⌘⇧V** 呼出面板。它和系统的「粘贴并匹配样式」同键，语义相近不会误伤；
若与其他工具冲突，到偏好设置改成 ⌘⌥V / ⌘⌃V 等（见 [4.1](#41-快捷键)）。

## 3. 日常使用

### 3.1 基本流程

```
复制任意文本/图片  →  ⌘⇧V 呼出面板  →  ↑↓ 选择  →  ↩ 粘贴到原应用
```

- 面板会在你**当前所在的 App** 上弹出，关闭后焦点自动回到该 App。
- 面板列出的每一项显示：缩略图/文本预览、来源 App、时间。
- 最近一次复制的内容自动置顶（同内容去重，只保留一行）。

### 3.2 快捷键总表

| 操作 | 按键 |
| --- | --- |
| 呼出 / 关闭面板 | `⌘⇧V`（可改） |
| 上下选择 | `↑` `↓` |
| 粘贴（等于回车） | `↩` 或 双击 |
| 关闭面板 | `esc` |
| 删除当前项 | `⌘⌫` |
| 置顶 / 取消置顶 | `⌘P` |
| 打开偏好设置 | `⌘,` |
| 搜索 | 直接打字（无需点搜索框，呼出即已聚焦） |

### 3.3 搜索

- 呼出面板后直接输入即可实时过滤，`⌘⌫` 清空输入。
- 匹配的是文本内容；模糊大小写不敏感。
- **图片条目只在搜索框为空时出现**（图片没有可搜索的文本）。
- 搜索词含 `%` `_` 等字符时按字面匹配（内部做了 LIKE 转义）。

### 3.4 置顶

`⌘P` 把当前项标记为置顶（顶部区域，带标记）：

- 置顶项**不参与**条数淘汰，只有手动删除或清空历史才会消失。
- 再次 `⌘P` 取消置顶。

### 3.5 删除

- `⌘⌫` 删除当前选中项；若该项有图片，`images/<sha256>.png` 同步删除。
- 删除不可撤销（无回收站）。

### 3.6 支持与不支持的内容

| 复制的内容 | 结果 |
| --- | --- |
| 纯文本 | ✅ 记为文本条目（多余空白/换行会被归一化） |
| 富文本（Word、网页、Pages 等） | ✅ **只保留纯文本**，格式全部丢弃 |
| 仅 RTF / HTML（无纯文本类型） | ✅ 从 RTF/HTML 里解出字符串后入库 |
| 图片、截图、复制图片 | ✅ 重编码为 PNG（无损、保留 alpha），按内容 SHA-256 去重 |
| TIFF | ✅ 统一转成 PNG |
| Finder 里的文件 / 文件夹 | ❌ 直接跳过（`public.file-url` 且无真实文本） |
| 密码管理器内容（concealed） | ❌ 默认跳过 |
| 临时 / 自动生成粘贴板内容 | ❌ 跳过（`Transient` / `AutoGenerated`） |
| Universal Clipboard（跨设备粘贴） | ❌ 不记录（`com.apple.is-remote-clipboard`） |
| 超过单图上限的大图 | ❌ 拒绝入库（默认 > 20MB，可调） |

### 3.7 粘贴到哪儿？

- 面板关闭时会**激活回**你呼出面板前的前台 App，所以只要呼出前把光标放在目标输入框里，回车就能直接粘贴到位。
- 未授权辅助功能时，回车只是把内容放进剪贴板，需要你手动 ⌘V。

## 4. 偏好设置详解

打开方式：菜单栏菜单 → **偏好设置…**，或面板内 `⌘,`。

### 4.1 快捷键

- 当前组合显示为一个按钮，点击进入录制态（显示「按下快捷键…」）。
- 必须包含至少一个修饰键（⌘ / ⌥ / ⌃ / ⇧），否则提示「需要修饰键，请重按…」。
- 录制中按 `esc` 取消，保持原快捷键。
- 旁边有「复位」按钮回到默认 ⌘⇧V。
- 全局热键用 Carbon `RegisterEventHotKey` 注册，**不需要**辅助功能权限即可呼出面板。

### 4.2 启动与粘贴

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 登录时自动启动 NanoClip | 开 | 通过 `SMAppService` 注册；下方会显示系统返回的登录项状态 |
| 回车后自动粘贴到当前应用 | 开 | 关闭后回车只复制不粘贴（适合只想当剪贴板增强的用户） |

同区域还会显示辅助功能授权状态（「已授权，回车可自动粘贴」/「未授权，回车只会复制到剪贴板」）。

### 4.3 历史与存储

| 选项 | 默认 | 范围 | 说明 |
| --- | --- | --- | --- |
| 保留条数 | 500 | 50–2000 | **未置顶**条目上限，超限从最旧的开始删 |
| 记录图片 | 开 | — | 关闭后新复制的图片不再入库（已有图片不受影响） |
| 单图上限 | 20 MB | 可调 | 超限的图片直接拒绝 |
| 图片总量上限 | 500 MB | 硬上限 | 超限从最旧的未置顶图片开始删 |

区域底部显示当前条目数/图片占用等统计。

### 4.4 忽略的 App

- 一张列表，默认已包含：1Password（1Password 7 / AgileBits）、Bitwarden、LastPass、Apple Passwords、钥匙串访问、KeePassXC、Dashlane、Enpass。
- 点 `+` 从「应用程序」里选择 App，加进去后**它复制的内容永远不会入库**。
- 选中一行按 `−`（或删除键）移除。
- 列表下方提示：「这些 App 复制的内容不会被记录。密码类 App 已默认加入。」

### 4.5 清空历史

「清空历史」按钮 = 清空元数据表 + 删除 `images/` 下的所有图片文件，**不可恢复**。

## 5. 隐私行为

- 数据**只在本机**：`~/Library/Application Support/NanoClip/`，不加密落盘、无云同步、无网络请求。
- 日志只记录条目数量/类型/耗时，**不记录剪贴板内容**（`NanoClip.log` 超过 512KB 自动截断）。
- 采集前过滤三类内容：忽略 App 名单、concealed/transient 类粘贴板类型、远端剪贴板类型。
- 程序不做任何联网行为，零第三方依赖。

## 6. 数据与清理

### 6.1 目录结构

```
~/Library/Application Support/NanoClip/
├─ history.sqlite3 (+ -wal / -shm)   # 元数据（WAL 模式）
├─ images/<sha256>.png               # 图片实体，内容寻址，天然去重
└─ NanoClip.log                      # 运行日志
```

偏好设置（快捷键、条数、忽略名单等）存在 `UserDefaults`：

```bash
defaults read com.jvz.nanoclip
```

### 6.2 查看数据库

```bash
sqlite3 ~/Library/Application\ Support/NanoClip/history.sqlite3 \
  "select id, kind, substr(content,1,40), image_bytes, source_app, pinned
   from items order by created_at desc limit 10;"
```

### 6.3 手工清理

```bash
# 只清图片（元数据仍保留，预览会缺失——不建议）
du -sh ~/Library/Application\ Support/NanoClip/images

# 彻底重置：先退出 App
pkill -x NanoClip
rm -rf ~/Library/Application\ Support/NanoClip
defaults delete com.jvz.nanoclip       # 连偏好设置一起重置
```

### 6.4 命令行启动参数

| 参数 | 作用 |
| --- | --- |
| `--show-history` | 启动即展开历史面板 |
| `--show-preferences` | 启动即打开偏好设置 |
| `--diagnostics` | 打印诊断信息（内存、条目数、登录项、辅助功能）后退出 |

```bash
open -a NanoClip --args --show-history
/Applications/NanoClip.app/Contents/MacOS/NanoClip --diagnostics
```

## 7. 卸载

```bash
# 1. 退出并关闭登录项
osascript -e 'quit app "NanoClip"'
#    或在偏好设置里先取消「登录时自动启动」，否则系统可能留下登录项记录

# 2. 删除 App 和用户数据
rm -rf /Applications/NanoClip.app
rm -rf ~/Library/Application\ Support/NanoClip
defaults delete com.jvz.nanoclip

# 3. 可选：移除辅助功能授权记录
tccutil reset Accessibility com.jvz.nanoclip
```

## 8. 故障排查

### 快捷键按了没反应

1. 确认在跑：`pgrep -x NanoClip`。
2. 确认没被别的工具抢占（Raycast、Alfred、其他剪贴板工具都可能占 ⌘⇧V）。
3. 换成更冷门的组合（如 ⌘⌥⇧V）试试。热键注册失败不会弹窗，只会写日志。
4. 看日志：`tail -f ~/Library/Application\ Support/NanoClip/NanoClip.log`。

### 回车没有自动粘贴

- **99% 是辅助功能未授权**：面板底部会显示「回车仅复制到剪贴板」提示，点「去授权」。
- 授权后仍无效 → 在辅助功能列表里**移除 NanoClip 再重新添加**（重建后签名 cdhash 变了）。
- 目标 App 自身屏蔽了合成事件（部分远程桌面/虚拟机会这样），只能手动 ⌘V。

### 重建后权限反复失效

ad-hoc 签名每次构建 cdhash 都变，系统认为这是「另一个 App」。解决方案：创建一次自签名证书，之后固定使用它：

```bash
# 钥匙串访问 → 证书助理 → 创建证书
#   名称: NanoClip Local   身份类型: 自签名根证书   证书类型: 代码签名
SIGN_IDENTITY="NanoClip Local" ./Scripts/build-app.sh
```

### 「登录时自动启动」提示无法定位应用

`SMAppService` 要求 App 位于 `/Applications`。先用 `Scripts/install.sh` 安装，再在偏好设置里勾选。

### 条数比设置的多 / 少的条目自己消失

- 置顶项不参与淘汰，所以总数可能超过「保留条数」。
- 图片总量超过 500MB 会从最旧的未置顶图片开始自动清理。

### 图片没被记录

- 检查偏好设置里「记录图片」是否开启。
- 单图是否超过 20MB 上限。
- 日志里会有 `image rejected` 之类的记录。

### 内存看起来偏高

`ps -o rss` 会把 AppKit/Foundation 等共享框架页也算进去（空 AppKit agent 也有 ~68MB）。
用活动监视器的「内存」口径（phys_footprint）才准确：

```bash
footprint -p "$(pgrep -x NanoClip)"    # 空闲约 16MB，反复开合面板后约 26MB 并稳定
```

### 数据库损坏

```bash
pkill -x NanoClip
sqlite3 ~/Library/Application\ Support/NanoClip/history.sqlite3 "pragma integrity_check;"
# 修不好就删库重来（历史会丢）：
rm -f ~/Library/Application\ Support/NanoClip/history.sqlite3*
```

### 面板弹出但空白

- 刚启动时数据库为空属正常，先复制点东西。
- 搜索框可能残留上次的搜索词，`⌘⌫` 清空。
- 历史被清空过 → `images` 与元数据都不存在了。

### 查看运行期诊断

```bash
/Applications/NanoClip.app/Contents/MacOS/NanoClip --diagnostics
```

会输出：bundle / version / hotkey / autoPaste / accessibilityTrusted / launchAtLogin(pref+system) / maxItems / recordImages / ignoredApps / store 路径 / items / imageItems / imageBytes / orphanImagesRemoved / rss。
注意它只报 RSS，phys_footprint 用上面的 `footprint` 命令看。

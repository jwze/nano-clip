# NanoClip — 轻量 macOS 剪贴板历史工具（实施计划）

## 摘要
新建 `/Users/jvz/code/NanoClip`：一个无 Dock 图标（`LSUIElement`）的菜单栏 agent app，用 **Swift + AppKit（不用 SwiftUI/xib/storyboard）+ 系统 libsqlite3**，无第三方依赖；`swift build` + 脚本打包成 `NanoClip.app`。

能力：全局快捷键 `⌘⇧V` 呼出浮层历史 → ↑↓ 选择 → `Enter` 自动粘贴到原应用；只保留**纯文本**与**图片**，**永不记录文件**；`Esc` 关闭；`⌘,` 打开偏好设置；开机自启；历史去重、置顶、搜索、条数与容量自动淘汰；忽略密码类内容与指定的来源 App。

目标：空闲常驻 RSS 约 **35–50MB**（用 `ps -o rss` / Instruments 实测验收），CPU 接近 0。

## 技术形态
- `Package.swift`（`swift-tools-version: 6.0`，`platforms: [.macOS(.v14)]`），单个可执行 target `NanoClip` + `NanoClipTests`。
- 入口 `Sources/NanoClip/main.swift`：`NSApplication.shared` + `AppDelegate`，程序化构建全部 UI；`LSUIElement=true`，单实例（已运行则激活后退出）。
- 打包：`Scripts/build-app.sh` → `swift build -c release`（仅本机 arch）→ 组装 `build/NanoClip.app`（`Contents/MacOS/NanoClip`、`Info.plist`、`AppIcon.icns`）→ `codesign`。`Scripts/install.sh` 拷到 `/Applications` 并重启。
- 签名：`SIGN_IDENTITY` 环境变量，缺省 ad-hoc（`-`）。**已知约束**：ad-hoc 每次重编译会改变 cdhash，辅助功能授权需重新授予；README 给出用自签名证书 `NanoClip Local` 持久授权的做法。
- 不引入 SwiftUI、GRDB、Sparkle；纯文本写入只用 `public.utf8-plain-text`，图片用 `public.png`。

## 核心行为规格
### 采集（`Capture/*`）
- `DispatchSourceTimer` 在主队列每 **0.35s** 读 `NSPasteboard.general.changeCount`（tolerance 0.2s）；变化且非自身写入 → 读取 item 数据（主线程，快速拷贝）→ 哈希/PNG 重编码/SQLite 写在后台串行队列（带 `autoreleasepool`）。
- 自身写入用 `expectedChangeCount` 白名单忽略，避免回环。
- 归一化规则（`CaptureRules`，纯值类型输入，可单测）：
  - 含 `public.file-url` / `NSFilenamesPboardType` 且**无** `public.utf8-plain-text`、`public.tiff` → **跳过（文件不入库）**。
  - 含纯文本 → 文本项：取 `.string`（天然无格式），trim 首尾空白，空串跳过，超 **1,000,000 字符** 截断并标记。
  - 否则含 `public.tiff`/`public.png`（或 `NSImage.fromPasteboard`） → 图片项；重编码为 PNG（保留透明通道），超过单图上限（默认 20MB）丢弃。
  - 忽略 pasteboard 类型 `org.nspasteboard.ConcealedType / TransientType / AutoGeneratedType`、`com.apple.is-remote-clipboard`。
  - 来源 App = 呼出前记录的 frontmost bundle id（若为 NanoClip 则用上一个非自身 App）；命中忽略列表则不记录。

### 存储（`Store/*`）
- 路径：`~/Library/Application Support/NanoClip/history.sqlite3`（WAL）+ `images/<sha256>.png`。
- 表：`items(id PK, kind 0=text/1=image, content TEXT, image_path TEXT, image_bytes INT, hash TEXT UNIQUE, source_app TEXT, created_at REAL, pinned INT DEFAULT 0)`；`hash = sha256(kind + payload)`。
- 去重：相同 hash 已存在 → 更新 `created_at`（置顶到最新）并删除被替换的旧图片文件；不产生新行。
- 淘汰：未置顶条数上限 **500**（偏好可调 50–2000）；置顶不参与淘汰；图片总占用硬上限 **500MB**，超限从最旧的未置顶项开始删（行 + 文件）。
- 查询：`fetch(limit=200, search)`；搜索对文本 `LIKE`（`ESCAPE '\'` 转义）与来源 App 名匹配，图片仅在空查询下出现；结果上限 200 行。
- 长期保持单条 SQLite 连接 + 复用 prepared statements；`deleteAll()` 供偏好设置"清空历史"。

### 呼出与粘贴（`HotKey/*`, `Paste/*`, `UI/HistoryPanel`）
- `HotKeyManager`：Carbon `RegisterEventHotKey`（**不需要**辅助功能权限），默认 `⌘⇧V`（会覆盖系统"粘贴并匹配样式"，语义相近；可在偏好设置改键，冲突时给出提示）；键位存 `UserDefaults`。
- 呼出：记录目标 App → `NSRunningApplication.activate()` → 显示 `NSPanel`（`[.borderless, .nonactivatingPanel]` + `canBecomeKey=true` 子类，`NSVisualEffectView` HUD 材质，圆角 12，阴影无标题栏，360×460，位于当前屏上方 1/3 居中）。
- 面板内容：搜索框（默认聚焦）+ `NSTableView`（view-based）：行高 48，左侧 20pt 类型图标或 34pt 圆角缩略图，主文案单行尾部截断，次行灰色小字「来源 App · 相对时间」，置顶行右侧 📌。
- 键盘：↑↓ 选择、`Enter` 粘贴（等同双击行）、`Esc` 关闭、`⌘⌫` 删除当前项、`⌘P` 置顶切换、输入字母进入搜索。
- 粘贴流程：写剪贴板（纯文本 `.string` 仅此类型；图片 `.png`）→ 记录 expectedChangeCount → `orderOut` → 目标 App 激活 → ~80–120ms 后 `CGEvent` 发送 `⌘V`。
- 权限降级：`AXIsProcessTrustedWithOptions` 未授权 → 只复制到剪贴板，面板底部提示「开启辅助功能以自动粘贴」+ 直达系统设置链接；偏好设置里有开关「呼出后自动粘贴」（关 = 仅复制）。
- 偏好设置 `⌘,`（懒加载单窗口，420×380，`NSStackView` 分组）：
  - 通用：开机自启、呼出快捷键（录制按钮 + 恢复默认）、自动粘贴开关
  - 历史：保留条数（stepper）、记录图片开关、单图上限（5/10/20MB）、清空历史
  - 忽略：App 列表 + 「添加应用…」（NSOpenPanel 选 .app 取 bundle id）/ 移除；内置默认忽略 1Password、Keychain、Bitwarden、LastPass、Passwords 等
- 菜单栏菜单：显示历史 `⌘⇧V`、偏好设置…、退出（`LSUIElement`，无 Dock 图标）。

### 开机自启
- `SMAppService.mainApp.register()/unregister()`，偏好设置与菜单项同步真实状态；首次启动默认注册（失败不阻塞，记 log 提示）。App 被移动后提示重新注册。

### 内存/体积策略（明确约束）
- 面板与偏好窗口按需创建，关闭后释放 `contentViewController`；列表页上限 200 行。
- `ThumbnailCache` 用 `NSCache`（countLimit 60 / totalCostLimit 32MB），面板隐藏即 `removeAllObjects()`。
- 图片 PNG 编码、哈希、SQLite 写入全在后台串行队列；无轮询文件、无常驻大数组、无 SwiftUI 运行时。
- release 构建开启 `-O` 与 dead code stripping；只构建本机架构；README 记录 `ps -o rss`/Instruments 基线。
- 验收目标：空闲 ≤ 60MB 为通过，力争 35–50MB；面板关闭后 RSS 回落不持续增长。

## 实施步骤（按顺序）
1. 骨架：`Package.swift`、`Scripts/Info.plist`、`build-app.sh`，空菜单栏 agent 可启动、无 Dock 图标。
2. 存储层 + 单测：SQLite 封装、去重、淘汰、图片文件 GC、搜索转义。
3. 采集层 + 单测：`PasteboardSnapshot` → `CaptureRules`（跳过文件/空白/敏感类型、1MB 截断），监控轮询接线。
4. 面板 UI：列表、缩略图、搜索、↑↓/Enter/Esc/删除/置顶。
5. 粘贴：写入纯文本/图片、自身写入忽略、CGEvent 粘贴、失败降级与权限引导。
6. 热键注册 + 录制改键 + 冲突提示。
7. 偏好设置窗口 + 开机自启 + 忽略应用列表 + 清空历史。
8. 图标生成、install.sh、内存实测与调优、README（含授权与签名说明）、首次 git commit。

## 测试与验证
- 自动：`swift build -c release`、`swift test`（去重/置顶保护/淘汰/空白与超长文本/文件与敏感类型跳过/搜索转义/图片文件删除）。
- 手动清单：
  1. 复制网页富文本 → 历史仅纯文本；粘贴到 TextEdit 得到无格式文本。
  2. 复制网页图片/截图 → 出现缩略图；重粘回目标应用为图片（PNG 保持透明）。
  3. Finder 复制文件 → 不入库。
  4. 1Password/Keychain 复制 → 不入库；把某 App 加入忽略列表后其内容不入库。
  5. `⌘⇧V` 呼出、↑↓、Enter 自动粘贴到原应用；未授权时降级为仅复制并显示引导。
  6. 退出重启（含重启 Mac）→ 自启生效、历史保留、置顶与条数设置保留。
  7. 连续复制 600 条/灌入大图 → 未置顶裁剪到 500、磁盘占用受限、图片文件无孤儿。
  8. 内存：冷启动、开合面板 20 次后 `ps -o rss` 不持续攀升。

## 假设与默认值
- 应用名 **NanoClip**，bundle id `com.jvz.nanoclip`，仅支持 macOS 13+（本机 27.2.1），只构建本机架构。
- 默认热键 `⌘⇧V`（覆盖系统"粘贴并匹配样式"，可改；备选 `⌘⌥V`）。
- 默认保留 500 条未置顶、单图 ≤ 20MB、图片总量 ≤ 500MB、开机自启默认开启。
- 第一版包含 搜索/置顶/删除（选项 2 的能力）以支撑偏好面板的完整度；**不含** iCloud 同步、加密存储、自动更新、URL 特殊处理、文件条目、富文本样式。
- 图片统一重编码为 PNG（无损、体积可控），按 sha256 去重；不保存原始 TIFF。
- 数据仅本地明文存储；清空历史 = 删表 + 删 images 目录。

## 实施结果与偏差

实际交付：`/Applications/NanoClip.app`（648 KB，ad-hoc 签名，`LSUIElement`），仓库 48 个文件，`swift test` 80 用例全绿（核心 54 + 面板/搜索/按键/偏好/热键录制 26）；运行期端到端已验证纯文本剥离、TIFF→PNG 保留 alpha、文件/密码类跳过、去重、`⌘V` 注入、焦点回归、登录项启用。

| # | 计划 | 实际 | 原因 |
| --- | --- | --- | --- |
| 1 | 空闲 `ps -o rss` ≤ 60MB | 78MB RSS / **16MB phys_footprint**（活动监视器「内存」） | 本机**空** AppKit 菜单栏 agent 基线即 68MB（RSS 含共享框架页）；App 自身占用仅比基线多约 6MB。两种口径均记录在 README。 |
| 2 | 单个可执行 target + 测试 | `NanoClipCore`（库）+ `NanoClip`（可执行）+ 两个测试 target | 纯逻辑需 `@testable` 单测；目录结构与计划一致，只是多了一层模块边界。 |
| 3 | 文本「trim 首尾空白」 | 只裁尾部空白与首尾空行，**保留行首缩进** | 复制代码块时保留缩进，避免粘贴回来变形。 |
| 4 | 偏好窗口 420×380 | 520×619（按内容自适应） | 否则中文标签、忽略列表与按钮会被裁切。 |
| 5 | `Enter` 自动粘贴 | 已实现，但需用户在系统设置授予**辅助功能**权限 | TCC 只能由用户授予；未授权时按计划降级为仅复制 + 面板底部提示 + 一键跳转。`⌘V` 注入链路已实测生效。 |
| 6 | UI 目录含 `ToastView.swift` | 未实现 | 失败只写日志；权限引导由面板底部提示按钮承担，暂无需要 toast 的交互。 |
| 7 | macOS 13+ | 实际最低 14.0（`platforms: [.macOS(.v14)]`） | 与计划「技术形态」一节一致，README 已注明。 |
